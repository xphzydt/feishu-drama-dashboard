# AI短剧制作统计组件

动态分秒时长卡片和团队同心进度环。每人一圈，亮色表示已完成，底色表示未完成；旁边列出分工、集数、总时长和积分。每个人的“查看剧集”按钮会在飞书内打开本人负责的剧集视图。

## 数据来源

通过飞书官方 SDK 读取当前多维表格中的人员进度记录，不把交叉统计矩阵当作明细记录。仓库不包含实际项目数据、表格地址、密钥或访问令牌。

数据表名称为“05 人员进度”，需要字段：制作人、分工说明、负责集数、已完成集数、累计成片秒数、累计积分。

## 使用地址

仪表盘添加自定义插件时使用：
- 同心环：https://xphzydt.github.io/feishu-drama-dashboard/?surface=dashboard&widget=rings
- 总时长：https://xphzydt.github.io/feishu-drama-dashboard/?surface=dashboard&widget=duration

侧边栏插件使用：
- 同心环：https://xphzydt.github.io/feishu-drama-dashboard/?surface=sidebar&widget=rings
- 总时长：https://xphzydt.github.io/feishu-drama-dashboard/?surface=sidebar&widget=duration

单独打开这些网址无法读取飞书数据，必须从飞书中的相应入口打开。

## 模板和查看权限

侧边栏按当前多维表格解析表名与字段，不保存旧表编号。仪表盘保存飞书的数据源引用，展示类型保存在自定义配置中；查看时按当前数据源重新解析字段。

整份多维表格创建副本后的真实数据绑定已验证。查看者需要能够读取源人员进度表；独立仪表盘分享、匿名查看与移动端展示均未完成验证。

## 个人剧集按钮

按钮按当前“02 剧集制作”中的“姓名｜我的剧集”视图名称准确匹配制作人。示例人员名称末尾的“（示例）”不计入视图姓名；正式成员直接用实际姓名。不保存固定的表格地址，不匹配以“(dashboard_view)”结尾的内部视图。新增成员时，请为其建立同名个人视图并设置相应筛选；缺少个人视图或没有读取权限时，按钮不可用。
