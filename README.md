# AI短剧制作统计组件

飞书多维表格仪表盘插件：动态分秒时长卡片、按制作人展示的同心进度环。

## 数据

运行时通过飞书官方SDK读取当前多维表格。仓库不包含表格地址、成员信息、项目记录、App Secret或访问令牌。

需要当前Base内的`05 人员进度`表，字段为：制作人、分工说明、负责集数、已完成集数、累计成片秒数、累计积分。首次创建组件时自动解析字段，配置保存在飞书内。未完成集数=负责集数-已完成集数。

## GitHub Pages

Pages来源设置为main分支的根目录。托管后在飞书仪表盘选择“添加组件→更多→添加自定义插件”，输入网页地址。

- `/?widget=duration`：总时长大字卡片
- `/?widget=rings`：团队同心进度环

标准SDK读取权限与使用者在飞书中的权限一致。实际部署后仍需在飞书内完成数据连接和刷新验证。

## SDK

使用飞书官方仪表盘插件示例所用的`@lark-base-open/js-sdk 0.4.1-beta.5`。附带的SDK许可见`SDK-LICENSE.txt`。
