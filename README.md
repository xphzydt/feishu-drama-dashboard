# AI短剧制作统计组件

看板从上到下依次显示团队已完成总时长、团队同心进度、积分消耗情况。积分区包含全部流水的累计总消耗、每人累计和按上海时区汇总的每人每日明细，可按月份与人员筛选明细。总时长以分秒显示。

每个个人表格视图对应一圈。从内向外按实际负责剧集的起始集号升序排列；起始集号相同时按结束集号排列，尚未分配剧集的视图排在外侧。右侧人员详情由上到下与内圈到外圈一一对应。新增视图后增加一圈，改名后同步名称，删除视图后移除对应圈。“查看剧集”按视图自身的编号跳转，改名不影响跳转。

## 建立个人视图

在“02 剧集制作”中创建表格视图，设置筛选“制作人＝该成员”。视图名称可自由修改，组件显示完整的视图名称。没有该视图时，不会仅因增加制作人选项或统计行而增加圈。未分配剧集的新成员视图会显示零集。

组件每10秒在可见时重新读取视图和数据；剧集、积分记录变化也触发刷新。内部以“(dashboard_view)”结尾的仪表盘视图不计入同心环。删除视图不会删除原表剧集。

## 数据来源

使用飞书官方 SDK，读取当前多维表格；“批量生成 / 分配剧集”入口仅在用户预览并点击确认后写入“02 剧集制作”。不保存实际项目数据、表格地址、密钥或令牌。

统计数据来自当前多维表格。

- “02 剧集制作”：制作人、所属项目、集号、完成集数、成片总秒数。
- “04 积分流水”：制作人、消耗积分、任务创建时间。

每圈的集数和时长来自对应视图的剧集；积分来自该制作人的全部积分流水。中央团队集数与总时长卡片按剧集总表统计，不会因重复视图重复计算。无需在“05 人员进度”另建行才能出现新圈。

## 批量生成和分工

在制作总看板顶部点击“批量生成 / 分配剧集”。输入总集数，按需填写剧名前缀，再添加“起始集—结束集—制作人”分工段。每段范围不得重叠，制作人选项实时读取02的字段。

- 批量生成：优先按团队剧集总览的行顺序填入空白记录，空位不足时再新增。仅剩集号的旧空位可以复用；有人员、状态、日期、时长或其他业务数据的记录不会覆盖。例如80集生成第1集至第80集，按分工段填写制作人，状态为待制作。前缀为空时使用“第1集”，填写前缀时使用“青禾 · 第1集”。
- 同一前缀与集号已存在的剧集会跳过，兼容“第01集”格式；有重复记录或名称与集号矛盾时停止，要求先核对。
- 批量分配已有剧集：只更新指定范围内已有记录的制作人，保留状态、日期、时长等其他字段。
- 必须先预览，再确认写入。写入前重新核对数据；每批最多200条，部分失败后重新预览以跳过已经创建的记录。

只有具有相应表格写入权限的用户可以完成操作。不会自动新建个人工作台。
